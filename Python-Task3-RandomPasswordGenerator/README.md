# 🔐 Random Password Generator

A secure and customizable **Random Password Generator** developed in Python as part of the **Oasis Infobyte Python Programming Internship (OIBSIP)**.

The application generates random passwords based on the user's selected length and character requirements, helping create strong passwords for different applications and accounts.

## ✨ Features

* 🔢 Generate passwords of customizable length
* 🔠 Include uppercase letters
* 🔡 Include lowercase letters
* 🔢 Include numbers
* 🔣 Include special characters
* 🎲 Generate random passwords using Python's built-in `random` and `string` modules
* 🛡️ Helps create stronger passwords by combining multiple character types
* 💻 Simple command-line interface

## 🛠️ Technologies Used

* **Python 3**
* `random`
* `string`

## ⚙️ How It Works

The program allows the user to specify the desired password length and character types.

It then:

1. Creates a pool of available characters.
2. Adds the selected character types to the pool.
3. Randomly selects characters from the pool.
4. Combines them to generate the final password.
5. Displays the generated password to the user.
