A Python-based voice assistant capable of accepting voice commands and performing various tasks.

#### Features

* 🎙️ Voice input using Speech Recognition
* 🔊 Text-to-Speech responses
* 🕐 Time and date information
* 🌐 Web search functionality
* 🌦️ Weather information using an API
* 📧 Email functionality
* ⏰ Timed reminders
* 🧠 Knowledge-based responses
* ⚙️ Custom commands using JSON

#### Technologies & Concepts

* Python
* Speech Recognition
* Text-to-Speech
* JSON
* APIs
* Web Browser Automation
* Email Automation
* Date & Time Handling

### 🔐 Task 3: Random Password Generator

A Python-based **Random Password Generator** designed to create strong and customizable passwords using different combinations of characters.

The program allows users to generate passwords based on their required length and selected character types.

#### Features

* 🔢 Customizable password length
* 🔠 Uppercase letters
* 🔡 Lowercase letters
* 🔢 Numbers
* 🔣 Special characters
* 🎲 Random password generation
* 💻 Simple command-line interface

#### Technologies & Concepts

* Python
* `random` module
* `string` module
* Functions
* User Input
* Randomization
* String Manipulation

**Project Folder:** `Python-Task3-RandomPasswordGenerator/`
